# Manual Windows integration checklist

These are **not executed** unless a dated result is added. They require an interactive Windows session and intentional desktop interaction. Never automate them on someone else's active work session.

## Safety first

- [ ] Launch without activation or a taskbar button for the overlay. The tray icon appears.
- [ ] Press Win+D: rug is above real icons and below normal windows when apps return.
- [ ] Ctrl+Alt+Esc hides the rug immediately; Ctrl+Alt+R restores it on the desktop.
- [ ] Tray Hide, Show and Exit work, including when fabric is folded or a drag was interrupted.
- [ ] Occupy the emergency hotkey with another test utility: rug stays hidden and settings explain the conflict.
- [ ] Outside the rug and on its shadow, desktop selection/context menu and icons work normally.
- [ ] No desktop files, shortcuts, attributes, positions or targets change after use and exit.

## Fabric and input

- [ ] Drag center, edges and all four corners; perform rapid movement, long holds, release outside the rug and across the screen edge.
- [ ] Corners lift, wrinkles form and the fabric settles without visible explosions or stuck capture.
- [ ] Right-click Peek, timer restore, second Peek command, emergency hide during Peek and real desktop double-click activation all work.
- [ ] Double-click roll and unroll; grab a rolled rug; scroll rotation; tray flatten, restore, four sizes and scale adjustment.
- [ ] A single click leaves a roll intact; smooth/high-resolution wheel input, multi-notch scrolls and swapped primary mouse buttons behave correctly.
- [ ] Hide/Peek between clicks does not create an accidental double-click; geometry commands during an active or pending gesture release ownership cleanly.
- [ ] An application gaining focus stays above the rug; exposed desktop retains it and a covering opaque application pauses animation.
- [ ] Configure timed, toggle and hold Peek; change its shortcut; test conflict rollback and optional right-click activation.
- [ ] Touch/pen drag, corner pressure, additional-pointer rejection, cancellation, barrel Peek and promoted-mouse suppression on real devices.
- [ ] Verify table-top lighting, weave, fringe and shadow at 100%, 125%, 150% and 200% scaling.

## Shell and displays

- [ ] Windows 10 with Explorer; Windows 11 with Explorer.
- [ ] Desktop icons enabled, disabled, rearranged, resized and dragged during Peek. Bumps refresh without moving icons.
- [ ] Restart Explorer intentionally. Tray returns, discovery recovers, and icon tracking diagnostics are accurate.
- [ ] Two or more monitors, one with negative X/Y origin, mixed DPI; drag continuously across boundaries and verify size/position continuity and persistence.
- [ ] Disconnect the saved monitor; change resolution, scale and primary display; rug stays recoverable.
- [ ] Full-screen app, Win+D twice, Task View and virtual desktop switches.
- [ ] Lock/unlock, suspend/resume and remote-session disconnect/reconnect; animation stops and recovers.

## Product lifecycle

- [ ] All three patterns and a custom portrait/landscape image; image aspect ratio is preserved and original file remains byte-identical.
- [ ] Compare red/ivory portrait and neutral landscape materials to the supplied references; verify buried fringe stays hidden in folded/rolled poses.
- [ ] Language, sound, Peek, icon bumps, startup, shadow and lighting preserve current folds; unrelated preferences remain usable if an already-loaded custom image's source becomes unavailable.
- [ ] Missing/corrupt custom image gives a useful fallback, never a crash or overwritten image.
- [ ] Sounds are off initially; optional sounds remain quiet and non-repetitive.
- [ ] Settings remain readable and keyboard-accessible at small work areas and high DPI.
- [ ] Save preferences, exit and relaunch; center, monitor, size, rotation and appearance persist.
- [ ] Launch a second instance; only one rug and tray icon remain.
- [ ] Opt in to sign-in launch and verify it. Disable and confirm only DesktopRug's own Run value is removed.
- [ ] Unreadable/corrupt settings recover with a preserved backup.
- [ ] Profile a real 60-second drag on target hardware; compare Balanced, High and Economy, resting CPU, lock and hidden CPU.

Do not enable sign-in launch or change the real shell/display state merely to clear this checklist without the user's permission to interrupt their session.
