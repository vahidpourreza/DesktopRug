# Desktop Rug 0.3.1 — Reliable release publication

Includes the English/Persian interface from 0.3.0, plus a maintenance fix for the release workflow.

- Choose **Settings → Language → English / فارسی**. Persian uses RTL layout; changing languages preserves unsaved edits, and saving just the language preserves the current rug state.
- GitHub may briefly return stale data after creating a draft or uploading its asset. The release workflow now waits for verified read-after-write results with bounded retries, without repeating mutations or replacing existing downloads.
- Build, automated tests, asset integrity and source-tag checks remain required before publication. The earlier tag is retained unchanged.

Download `DesktopRug-0.3.1-win-x64.zip`, extract it, and run `DesktopRug.exe`. Exit any older running copy from its tray menu first. Existing settings are retained. Keep the license notices beside the executable; no separate .NET runtime is needed.

The language implementation passed 92 tests and the self-contained 0.3.0 build's off-screen language checks. This maintenance change does not alter its runtime behavior. The tagged workflow builds and tests 0.3.1 again before publishing.

**Unsigned Windows 10/11 x64 preview.** Physical Windows 11, mixed-DPI hardware, touch/pen and disruptive shell/session acceptance remain pending; no installer is included. See [validation](https://github.com/vahidpourreza/DesktopRug/blob/v0.3.1/docs/VALIDATION.md).
