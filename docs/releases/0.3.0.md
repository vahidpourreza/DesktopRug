# Desktop Rug 0.3.0 — English and Persian

## Changes

- Added **Settings → Language → English / فارسی**, with immediate preview and saved preference.
- Translated settings, tray menus, validation and diagnostic messages. Persian uses right-to-left layout; shortcut keys, filenames and custom rug images retain their original orientation.
- Switching languages preserves unsaved settings. Cancel discards the language preview; Save updates the application and keeps the language after relaunch.
- A language-only save leaves the current cloth, position, roll state and desktop surfaces intact.
- Added a tag-driven release workflow. Each completed change set now receives a versioned GitHub release with a portable Windows ZIP and license notices.

## Download and upgrade

Download `DesktopRug-0.3.0-win-x64.zip`, extract it, and run `DesktopRug.exe`. This self-contained x64 build requires Windows 10/11, but no separate .NET installation or administrator privileges.

If an older copy is running, choose **Exit** from its tray menu first. Keep the license notices with the executable. Existing preferences remain in `%LOCALAPPDATA%\DesktopRug\settings.json`; old settings default to English until another language is saved.

## Verification and preview status

The Release build and 92 automated tests pass. Off-screen language checks cover persistence, cancel/save, unchanged cloth on language-only saves, translated RTL/LTR layouts, narrow-window bounds, and unmirrored artwork without taking desktop focus.

This remains an **unsigned preview**, not a completed hardware acceptance release. Physical Windows 11, multiple monitors/mixed DPI, touch/pen devices and disruptive shell/session scenarios remain unverified. Installer work remains deferred. See [validation](https://github.com/vahidpourreza/DesktopRug/blob/v0.3.0/docs/VALIDATION.md) and [manual checks](https://github.com/vahidpourreza/DesktopRug/blob/v0.3.0/docs/MANUAL_TESTS.md).
