# Desktop Rug 0.4.0 — Detailed rugs and interaction fixes

## Three replacement materials

- **Rich red Persian**, **Light ivory Persian**, and **Neutral tonal** now use the supplied reference artwork, retaining its fine ornaments, borders and palette.
- The two portrait materials and the landscape material have their own proportions, high-resolution textures, matching fringe edges and English/Persian names.
- Original PNGs are embedded unchanged; the app samples the fabric body and adds live lighting, shadows and depth-aware fringe. No runtime image download is needed.
- Settings previews fit the full rotated artwork; older saved pattern choices remain compatible.

## Fixed behavior

- Double-click unroll works on an already rolled rug; a single click no longer starts unfolding it.
- Actual drags begin after the Windows movement threshold, with shared gesture ownership and safe cancellation across surfaces.
- High-resolution wheel deltas accumulate correctly, multiple notches retain their magnitude, and swapped primary mouse buttons are respected.
- Hide/Peek/capture loss reset stale double-click sequences. Geometry commands release gestures safely, and Restore keeps the saved position.
- Language, sound, Peek, startup, icon-bump, shadow and lighting changes preserve the existing cloth and loaded image. An unavailable custom-image source no longer blocks unrelated preferences.
- Settled rotated portrait cloth can sleep properly, and rolls near viewport edges remain reachable.
- Buried fringe is occluded by nearer fabric instead of appearing through a roll. New pattern geometry fits rotated display bounds.

## Verification and upgrade

135 automated tests pass, including new cloth, material and occlusion regressions. Additional isolated checks cover language/persistence, 36 interaction regressions, material renders, and native/off-screen integration. The three new materials measured about 59.9 FPS in the off-screen WPF pipeline on the test machine. Details and limitations are in [validation](https://github.com/vahidpourreza/DesktopRug/blob/v0.4.0/docs/VALIDATION.md).

Download **`DesktopRug-0.4.0-Setup-x64.exe`** for per-user installation, a Start Menu shortcut and uninstall support. Setup requires no administrator rights, keeps desktop shortcuts optional, and does not automatically launch the app or enable startup. Uninstall preserves user settings and removes a sign-in entry only when it belongs to that installation. Installation, same-version reinstall, running-app protection and uninstall are gated by smoke tests on disposable GitHub-hosted Windows runners before publication.

The portable `DesktopRug-0.4.0-win-x64.zip` is also included. Exit an older copy from its tray menu before upgrading or switching copies. Existing preferences are retained; keep the license notices with the portable executable.

**Unsigned Windows 10/11 x64 preview.** This is a broad automated/off-screen test pass, not a claim that every possible interaction or hardware configuration was tested. Physical Windows 11, touch/pen, mixed-DPI displays and disruptive shell/session acceptance remain pending.
